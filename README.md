# simple-diceGame 
<br />
🎲 Simple Dice Game <br/>

&emsp;&emsp;A lightweight, two-player dice game where luck decides the winner!

🎮 How to Play

Players: Gather two players (Player 1 and Player 2). Each player gets one standard 6-sided die.

Roll: Click the Roll button to roll both dice at the same time.

Win Condition:

The player whose die shows the highest number of dots wins the round!

If both dice show the exact same number of dots, the game ends in a Draw.

🚀 Getting Started

Clone or download this repository:

git clone https://github.com/GDenven/simple-diceGame.git


Open the project folder and run the game (e.g., open index.html in your browser or run your main script).

Press Roll and have fun!
